---
title: "MCP server (deprecated)"
description: "The Miramarket MCP server is deprecated. Use the CLI instead."
---

The Miramarket MCP server (`@miramarket/mcp`) is deprecated and no longer recommended.

It required installing and signing in via the [CLI](/cli) anyway — the MCP server reads the same signed-in session the CLI writes, there is no separate MCP login — so it never reached an agent host the CLI couldn't already reach, while exposing a narrower set of tools than the CLI's own command surface.

## Use the CLI instead

```bash
npm install -g @miramarket/cli
```

See the [CLI page](/cli) for the full walkthrough, including sign-in and using it with an AI agent. It works with any agent host that can run shell commands — Claude Code, CI, and similar.

If your agent host cannot run shell commands at all (for example, a browser-based MCP-only client with no local install), Miramarket does not currently have a supported integration path for it.
