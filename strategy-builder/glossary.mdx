---
title: "Glossary"
description: "Important Miramarket words and what they mean in the app."
---

Use this glossary when a word in the builder is unfamiliar.

| Term | Meaning |
| --- | --- |
| Action | A node that tells the strategy what to do after a condition continues. |
| Allocation | The percentage of the available amount assigned to an action. Actions in one split must total `100%`. |
| Canvas | The workspace where strategy nodes and their order appear. |
| Close time | The time when a market stops accepting activity. It can differ from the time the market resolves. |
| Condition | A node that checks a price, time, or resolution rule before the strategy continues. |
| Sign in | The top-bar button used to set up your Miramarket account, required before **Run Live**. Signing in and adding funds does not start a live run. It is different from a Wallet action. |
| Hold | A Utility action that keeps the current position open and can continue to a child condition. |
| Market | A prediction market question or a named outcome within a market card. |
| Market action | An action that buys the selected `YES` or `NO` side of a market outcome. |
| Miramarket | The product for building and running prediction market strategies. |
| NegRisk market | A grouped event with mutually exclusive named outcomes. Select one named outcome, then choose its `YES` or `NO` side. |
| Named outcome | A specific option inside a multi-outcome market card, such as a team or person. |
| New Strategy | The top-bar button that starts a fresh strategy draft. |
| Outcome | A possible result or named option in a market. |
| Polymarket | The prediction market venue currently supported by Miramarket. |
| Price | The displayed current cost for a selected side, often shown in cents. |
| Price Condition | A condition that checks a selected market side against a price threshold. |
| Recurring market | A market family that repeats on a schedule, such as `5m` or daily. |
| Resolution | A condition that branches according to a selected market outcome. |
| Simulate | The top-bar action that starts a simulated run without placing real trades. |
| Run Live | An available run type that can use real funds. Execution and fills are not guaranteed. |
| Strategy | A complete plan made from markets, conditions, and actions. |
| Strategy builder | The app workspace at `app.miramarket.org`. |
| Template | A ready-made strategy you can start from instead of building node by node. Some templates apply immediately with markets already chosen; others ask you to fill named market slots. |
| Time Condition | A condition that checks a time before market close or a specific time. |
| Utility | The **Market** tab section that contains non-market actions such as **Hold**. |
| Wallet action | An action that directs its allocation to a Wallet destination. |
| `YES` | The side for a selected named outcome happening. |
| `NO` | The side for a selected named outcome not happening. |
