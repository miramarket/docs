The strategy builder is the workspace where you create a strategy visually. You use the left panel to choose building blocks, then place them on the canvas.

<img src="/images/tutorial/builder-overview.png" alt="Miramarket strategy builder with the top bar, market panel, and canvas shown" />

## Main areas

| Area | What it does |
| --- | --- |
| Top bar | Starts a new strategy, runs a demo, opens run options, and connects a wallet. |
| Left panel | Shows markets, conditions, wallet actions, and utility actions. |
| Canvas | Shows the strategy you are building. |

## Basic flow

1. Choose a market or condition from the left panel.
2. Add it to the canvas.
3. Set the rule or outcome.
4. Run a demo.
5. Review the result before using real funds.

## What to build first

Start with one condition and one action. For example: "If a market price is above 50 cents, buy `YES`."

That pattern is enough to learn how the builder works.
