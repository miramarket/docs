The strategy builder is where you create a strategy visually. Choose nodes in the left panel, then click to add them or drag them onto the canvas.

<img src="/images/tutorial/builder-overview.png" alt="Miramarket strategy builder with the top bar, market panel, and canvas shown" />

## Main areas

| Area | What it does |
| --- | --- |
| Top bar | Starts a new draft, runs a demo, opens run options, and connects a wallet. |
| Left panel | Switch between **Condition** and **Market** to find nodes. |
| Canvas | Shows the nodes and their order in the strategy. |

## Nodes on the canvas

Every strategy starts with a node. A condition checks a rule. A market action buys a selected outcome. **Hold** keeps the current position open. **Wallet** directs funds to the selected wallet destination.

Click a palette card to add it relative to the node you selected. Dragging is useful when you want to place a node before, after, or below another node. The canvas arranges the resulting path for you; you do not need to draw connectors manually.

## A simple strategy

Start with one condition and one market action. For example:

> If the selected outcome is above `50¢`, buy its `YES` side.

One action receives a `100%` allocation by default. When a condition has more than one action, make sure the allocations add up to `100%`.

## Build safely

Use **Run Demo** before **Run Live**. A live run can use real funds. If the canvas has an active run, editing is locked until that run is no longer active.
