---
title: "Run demo or live"
description: "Understand the difference between simulated and live strategy runs."
---

Miramarket gives you two ways to run a strategy: **Run Demo** and **Run Live**.

<img src="/images/tutorial/run-options.png" alt="Run menu with Run Demo and Run Live shown" />

## Run Demo

Use **Run Demo** to test a strategy without placing real trades.

Demo mode is useful for checking:

- Whether your condition is set correctly.
- Whether the action is attached to the right market.
- Whether the selected outcome is `YES` or `NO`.
- Whether the allocation looks right.

Run demo first, even for simple strategies.

## Run Live

Use **Run Live** only when you are ready to use real funds.

Live mode may require you to connect a wallet and have funds available. Live trades can lose money.

## Connect wallet

Use **Connect** in the top bar when you are ready to sign in with a wallet.

<img src="/images/tutorial/top-bar-run-demo-connect.png" alt="Top bar with Run Demo and Connect shown" />

Connecting a wallet does not mean you should run live immediately. Review the strategy first.

## Safe workflow

1. Build the strategy.
2. Run a demo.
3. Fix anything that looks wrong.
4. Review the market, outcome, condition, and allocation.
5. Connect wallet.
6. Use **Run Live** only if you accept the risk.

## When not to run live

Do not run live if:

- You do not understand the market.
- You are unsure whether `YES` or `NO` is correct.
- The price or close time looks wrong.
- You have not tested with **Run Demo**.
- You are not comfortable losing funds.
