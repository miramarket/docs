---
title: "Connect an AI assistant"
description: "Let an AI assistant such as Claude Code use your Miramarket account through the MCP server, choose what it may do, and stay in control of real money."
---

Miramarket's MCP server lets an AI assistant work with your account. You can ask it to show your strategies, build a strategy from a description, run a simulation, or start a live run. You approve the connection once in your browser, you choose what it may do, and you can disconnect it at any time.

The assistant can never withdraw money. Withdrawals are always made by you, in the app.

If you are setting up an agent or writing code against the server, see the [MCP reference](/mcp-reference).

## What you need

- A Miramarket account. To start live runs, your account setup must be finished: policies accepted and wallet delegated, as described in [CLI: finish account setup](/cli#finish-account-setup).
- An AI assistant that supports MCP servers: Claude Code, Claude on the web, desktop, or mobile, ChatGPT, or Grok.

## Connect Claude Code

Add the server:

```bash
claude mcp add --transport http miramarket https://api.miramarket.org/mcp
```

Then type `/mcp` in Claude Code and choose **miramarket**. Your browser opens the Miramarket approval page.

## Connect Claude, ChatGPT, or Grok

Web and app assistants connect with the same address, `https://api.miramarket.org/mcp`, added as a custom connector. Menu names change from time to time, so look for adding a custom connector or MCP server in the assistant's settings.

- **Claude on the web, desktop, or mobile:** add a custom connector with the address in Claude's settings.
- **ChatGPT:** turn on developer mode in ChatGPT's settings, then create a connector with the address. Developer mode is not available on every plan.
- **Grok:** add a custom connector, or MCP server, with the address.

Each one then opens the Miramarket approval page, the same as for Claude Code.

Other assistants that support remote MCP servers with OAuth sign-in connect the same way.

## Approve the connection

The approval page shows which app is asking. If the app is marked **unverified**, it registered itself rather than being identified by its publisher: approve it only if you just started the connection yourself.

Choose what the assistant may do:

- **Read your account** is always on: your strategies, runs, and committed funds.
- **Create strategies** lets it build strategies, save them as drafts, and run simulations.
- **Trade with real money** lets it start live runs on its own, up to a budget you choose, and ask you to approve any run beyond it. It is on by default with a `$100` budget.
  - **With trading off,** the assistant cannot start live runs or ask you to approve one. You start live runs yourself in the app.
  - **A lower budget** means more of its live runs wait for your approval. A run that fits in what is left of the budget still starts right away.

**Approve** becomes available a moment after the page loads. The connection lasts 90 days; after that, the assistant asks you to sign in again.

## Your budget for live runs

The budget is the most the assistant may have in live runs it started on its own. A run counts against the budget for as long as it has money in the market, even after it finishes, until its positions close.

- A live run that fits within the budget starts right away.
- A live run that would go over waits for you. The assistant sends you a link to **Connected agents**.

To answer a waiting run, open **Connected agents**: choose it in the account menu at the top right of the app, or go to `app.miramarket.org/settings/agents`. Each request shows the assistant, the strategy, and the amount. Choose **Approve** to start it or **Deny** to refuse it. Requests you do not answer expire after a day. If you approved a run but it did not start, it stays listed with **Start now**.

To change the budget, choose **Change budget** under the assistant on **Connected agents**, enter the new amount, and choose **Save**. The new budget applies from the assistant's next live run. Runs already going keep running, and runs waiting for you still need your answer. The assistant itself can never change its budget.

## See and disconnect assistants

**Connected agents** (in the account menu, or at `app.miramarket.org/settings/agents`) lists every assistant you connected: what it may do, its budget, when it was last used, and when the connection ends. You can change an assistant's budget there.

**Revoke** stops an assistant at its next request. Live runs it already started keep running; stop them from your strategies in the app.

## What you can ask it to do

- Show your strategies, how their runs are going, and how much money is committed.
- Build a strategy from a plain-English description, using the same strategy assistant as the app. If your description could mean several markets, it asks you which one. By default the strategy uses two venues: a trade you name gets a related position on another venue for 30% of the budget. Say "just" or "only" to keep one ([details](/strategy-builder/assistant#strategies-use-more-than-one-venue)).
- Check a strategy, save it as a draft, or run it as a simulation.
- Start a live run, within your budget or with your approval.
- Stop a run. Stopping a live run sells its open positions at market.
- Point you to the app when you want to withdraw.

Claude Code asks for your permission before every live start and every stop. Other assistants have their own confirmation settings; check them before you allow trading.

## See what a strategy does

When the assistant builds or saves a strategy, it shows it to you before anything else happens: each leg with its venue, market, side, amount, and leverage, the total, how the strategy runs, and anything that was substituted or added.

- In Claude and ChatGPT, this appears as a strategy card in the chat, with an **Open in Miramarket** button.
- In other assistants, it appears as a short summary with a link.

A strategy the assistant has only built, and not saved, opens in the builder, where you can review it and save it yourself. A saved strategy opens on its own page in the app, with its runs and results.

Start with a simulation. Live runs use real funds, and execution and fills are not guaranteed. Leverage on perps magnifies losses, and a position can be liquidated.
